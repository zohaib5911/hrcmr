## Materials and shared system review

- **Pass — material recipes (§5.3–5.4):** `globals.css` defines chrome at 72% opacity, sheet/popover surfaces at 92%, `saturate(180%) blur(20px)`, unsupported-blur and reduced-transparency solid fallbacks, layered light shadows and dark hairline elevation. Sidebar, toolbar, bottom tabs and marketing nav consume `material-chrome`; Sheet, Dialog, Popover and Menu consume `material-sheet`. Fix composition/contrast where needed rather than globally increasing blur or introducing arbitrary opacity values.
- **Pass — typography, tokens, icons (§5.2–5.4, §5.10):** shared font stack/self-hosted Inter, app/marketing scales, tabular table/time/KPI numbers, radius tokens and Lucide 1.5 px icons exist. The queue identifies consumers bypassing these components, not a missing token system.
- **Pass with scoped gaps — depth/layout (§5.1, §5.6):** signed-in chrome, grouped settings and responsive bottom tabs are recognisable and consistent. Mobile label crowding, the small toolbar title, repeated empty actions and legacy admin tables are the main departures. Cards already have quiet elevation; do not add extra borders across all app pages.
- **Source review — motion (§5.5):** sidebar width transitions, reduced-motion classes and KPI count-up exist. Dialog zoom uses 0.95 rather than the specified 0.96; align the shared dialog motion constant in T25.2 while preserving reduced-motion fades. A still screenshot cannot certify smoothness or 60 fps.
- **Source review — keyboard/states (§5.7, §5.12):** global focus ring is 2 px accent + 2 px offset; Radix handles dialog focus/Escape; EmptyState has the 64 px glyph treatment. Overlay evidence records Escape closing for the sampled layers. General app loading is the splash (B), not layout-matched skeletons. The full QA checklist remains a verification requirement after each fix, not an audit pass inferred from screenshots.
- **Assets (§5.10; plan L25):** no new artwork or third-party brand assets introduced; retain Lucide, self-hosted Inter and real app product shots. The map replacement must use properly licensed geographic data, not Apple assets.
